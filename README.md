# Order Management Dashboard
## B.Tech CSE Mini Project

A full-stack Order Management Dashboard built with HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

### Quick Start

1. Make sure MongoDB is running locally.
2. Open a terminal in the `backend/` folder.
3. Run:
   ```
   npm install
   npm start
   ```
4. Open your browser and go to: **http://localhost:5000**
5. Login with → **Username:** `admin` | **Password:** `admin123`

### Features
- Admin Login with JWT authentication
- Dashboard with animated stats (Total, Pending, Processing, Delivered, Cancelled, Revenue)
- View all orders in a table
- Add new orders
- Edit existing orders
- Delete orders (with confirmation modal)
- Search orders by customer name
- Filter orders by status
- Responsive dark-theme UI
- Auto-seeds 15 sample orders on first run
